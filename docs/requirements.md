# 要件(current-swimmer)

今のコード・テスト・bench の出力から起こした要件。数値の出どころはそれぞれの行に書く。

## 誰が・どんな場面で・何を楽しむか

- 流体の手触りを試したい人が、1 画面で尾を打ち、放して自分の後流に乗る差を見る(自由に泳ぐ・見本)。
- 物語「Upstream」: 水を抜かれる池から、年寄りのドジョウ Silt と 5 区間を遡る。押す・休むの拍子と
  2 つの選択(管か水路か・Silt のそばに残るか去るか)が、泳いだ秒とスタミナの赤い時間を入れ替える。
- 保存・得点・時間制限・外部通信・音声はない(`CLAUDE.md`)。

## 対応端末と入力

| 端末 | 入力 |
|---|---|
| PC | `W` / `Space` / `↑` で尾を打つ、`A` / `D` で向き、`P` で一時停止。画面のボタンも使える |
| iPhone 相当(縦 375×812・横 812×375) | 水面をタップ = そこへ泳ぐ(着くか 8 秒まで、0.6 秒打って 0.26 秒滑る拍子)。押したまま・なぞる = 指へ向かって泳ぐ(離すとタップした目的地へ戻る)。Left / Stroke / Right のボタンを押したままでも泳げる。一時停止中は水面のタップで再開 |

キー・ボタン・タップはどれも `turn` と `stroke` の 2 つの入力に変わるだけで、物理(`src/fluid.c`・`src/swimmer.c`)は同じ。

| 項目 | 基準 | 確かめ方 |

## 物語の数値(`src/journey.c`)

| 場面 | 効果 |
|---|---|
| outlet | Silt がいる間、尾を打つ消費 ×0.60 |
| culvert: 管 | 第 2 区間の噴流 ×1.30 |
| culvert: 水路 | 噴流 ×0.60・消費 ×0.40、途中の堰で輪の中に 18 秒(泳ぐ時間、流れは止まらない)とどまる |
| eddy | スタミナを 1.5 まで満たし、温い水(第 4 区間)の終わりまで上限 1.5 |
| taste | 第 4 区間の回復 ×0.12 |
| reeds: 残る | スタミナ満タン、Silt のそばの輪に 22 秒とどまる、第 5 区間の回復 ×1.40、堰板は葦を出たときに外れ噴流 ×1.30 |
| reeds: 去る | とどまらない、堰板は中間点で外れ噴流 ×1.22 |

流されて取った距離のうち 0.2 を失うと「流された」(輪の中にとどまっている間は数えない)。そのつど噴流 ×0.85、区間に 10 秒かかるごとにも ×0.85。
